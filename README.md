# SP Properties - Sonipat, Haryana

> **High Return House • आपका रियल एस्टेट पार्टनर**  
> A professional frontend real estate web application for SP Properties, a leading property dealer and real estate consultancy in Sonipat (NCR), Haryana, India.

---

## 🏢 About the Project

SP Properties specializes in:
- Residential Plots & Luxury Villas in Sector 14, Sector 15, Sector 8, Sector 12, Omaxe City, Express City, and TDI City Kundli.
- Commercial shops, SCO plots, and retail spaces.
- Verified registry, clear title deeds, and end-to-end property consultation.

This is a modern, responsive, frontend-only web application built with a premium Navy Blue (`#0b192c`), Crisp White (`#ffffff`), and Gold (`#c9a857`) aesthetic.

---

## 🛠️ Tech Stack

- **Framework**: [React.js](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v3](https://tailwindcss.com/)
- **Routing**: [React Router](https://reactrouter.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Plus Jakarta Sans & Playfair Display

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation & Local Run

1. Clone the repository:
   ```bash
   git clone https://github.com/vanshverma09/sp-property.git
   cd sp-property
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
